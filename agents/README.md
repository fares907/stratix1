# فريق STRATIX من الـ AI agents

15 موظف AI بيديروا الشغل اليومي للشركة، وانت رئيس مجلس الإدارة.

## اليوم بيمشي إزاي

| الوقت (القاهرة) | اللي بيحصل |
|---|---|
| 9:17 الصبح | الكشّاف بيدوّر في بنها ← المؤهِّل ← فحص الموقع والأمان ← **اجتماع الصبح** ← الرسايل ← الوارد ← GitHub |
| كل ساعتين | قراية ردود العملاء والرد عليها ← تنفيذ اللي وافقت عليه |
| 6:43 بالليل | **اجتماع آخر اليوم** ← التقرير اليومي ← تليجرام |

**في الاجتماع:**
1. كل موظف بيعرض شغله، مبني على أرقام حقيقية بيحسبها الكود، وممكن يقترح فكرة.
2. الناقدة بتعترض وبتقيّم الأفكار، وبتحدد مين لازم يرد.
3. المدير التنفيذي بيوافق على كل فكرة أو يرفضها، ويكتب السبب، ويوزّع المهام.

كل ده بيبان لايف في **غرفة الاجتماعات**، والأفكار في صفحة **الأفكار والقرارات**. وتقدر **تكلّم أي موظف** من اللوحة وتسأله ليه عمل حاجة، وأي توجيه تقوله بياخده في الاجتماع الجاي.

## الموظفين

| القسم | الموظفين |
|---|---|
| الإدارة | نادر (المدير التنفيذي)، سلمى (الناقدة) |
| المبيعات | كريم (الكشّاف)، هاني (المؤهِّل)، ليلى (الكاتبة)، عمر (الإرسال والمتابعة)، منى (خدمة العملاء) |
| العمليات | مصطفى (مدير المشاريع)، طارق (المالية، قراية بس) |
| الموقع والأمان | يوسف (مراقب الموقع)، زياد (سايبر سيكيوريتي)، نور (الزوار)، رامي (الاشتراكات والبنية) |
| التطوير | أحمد (المطوّر)، رنا (مراجعة الكود) |

كل واحد ليه موديل أساسي وموديل احتياطي من مزوّد تاني. تقدر تعيّن موظفين جداد أو تقيل أو تغيّر الموديل من اللوحة.

## قواعد ثابتة في الكود (مش في الـ prompt بس)

- **إيقاف الكل:** من اللوحة، أو اكتب `/stop` في تليجرام. أي طلب للموديل وأي إرسال وأي أداة بيقفوا. ولو قاعدة البيانات مش بترد، الكل بيقف.
- **الرسايل** بتتبعت أوتوماتيك، إلا لو فيها **سعر برّا 2000–3000 جنيه، أو ميعاد تسليم، أو خصم أو ضمان**. ساعتها بتروح لصندوق موافقاتك.
- **حد يومي** للإيميلات (15 في اليوم)، وفي آخر كل رسالة طريقة لإلغاء الاشتراك، واللي يلغي مابنكلموش تاني أبدًا.
- **الصلاحيات:** أي موظف يحاول يستخدم أداة مش بتاعته الكود بيرفض. المالية بتقرا بس. فريق التطوير مايقدرش يعمل merge.
- **البيانات الحساسة** (عملاء وفلوس) مابتروحش لمزوّد بيستخدم البيانات المجانية في التدريب.
- **الأرقام** في الاجتماعات والتقارير كلها من قاعدة البيانات. رأي الموظف بيتكتب على إنه رأي، ولو مش متأكد من حاجة بيقول.

## واتساب

المحلات اللي عندها رقم بس رسايلها بتبقى **جاهزة** في صفحة **البريد**، وجنبها زرار "افتح في واتساب" بيفتح المحادثة والرسالة مكتوبة. إرسال واتساب أوتوماتيك من غير WhatsApp Business API الرسمي بيعرّض رقمك للحظر.

## التشغيل لأول مرة

### 1. Supabase (قاعدة البيانات)
1. اعمل مشروع مجاني على supabase.com.
2. من **SQL Editor** شغّل ملفات `supabase/migrations/` بالترتيب (0001 ← 0005)، كل ملف مرة واحدة.
3. من **Authentication → Users** اعمل حساب لنفسك، وبعدين في SQL Editor شغّل:
   `insert into owners (user_id) select id from auth.users where email = 'إيميلك';`

### 2. المفاتيح (كلها مجانية)
- **Gemini:** aistudio.google.com
- **Groq:** console.groq.com
- **Cerebras:** cloud.cerebras.ai
- **OpenRouter:** openrouter.ai
- **Gmail:** فعّل 2-Step Verification، وبعدين اعمل **App password** (يفضّل يكون إيميل مخصوص للشغل ده).
- **تليجرام:** اعمل بوت من @BotFather عشان تاخد التوكن، وابعت للبوت رسالة، وبعدين اعرف رقم الشات بتاعك من `https://api.telegram.org/bot<TOKEN>/getUpdates`.
- **قاعدة بيانات الموقع:** اعمل في TiDB مستخدم **قراية بس** (الأوامر في أول `stratix_agents/sitedb.py`).

### 3. GitHub Secrets
من **Settings → Secrets and variables → Actions** ضيف:
`SUPABASE_URL`، `SUPABASE_SERVICE_ROLE_KEY`، `GEMINI_API_KEY`، `GROQ_API_KEY`، `CEREBRAS_API_KEY`، `OPENROUTER_API_KEY`، `GMAIL_ADDRESS`، `GMAIL_APP_PASSWORD`، `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID`، `SITE_DATABASE_URL`.

### 4. لوحة التحكم
1. ارفع فولدر `agents/dashboard` على Cloudflare Pages أو Vercel أو Railway، وخلّي الـ root directory هو `agents/dashboard`.
2. حط المتغيرات اللي في `dashboard/.env.example`.
3. اربط تليجرام باللوحة مرة واحدة:
   `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<رابط اللوحة>/api/telegram&secret_token=<TELEGRAM_WEBHOOK_SECRET>`

### 5. أول تشغيل
من **Actions → Agents → Run workflow** اختار `morning`. التشغيل المجدول نفسه بيشتغل بعد ما الشغل يتعمله merge على `main`.

## على جهازك (اختياري)

```bash
cd agents
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q                 # الاختبارات
python -m stratix_agents check      # يعرض الفريق
python -m stratix_agents models     # يتأكد إن أسماء الموديلات لسه موجودة عند المزوّدين
```

## حدود لازم تعرفها

- **الحدود المجانية** في `config/providers.yaml` تقديرية. لو مزوّد خلّص حدّه، الشغل بيتحوّل للاحتياطي، ولو الاتنين خلصوا الموظف ده بيستنى لبكرة.
- **الموقع مابيسجّلش عدد الزوار**، فنور (الزوار) بتحلل الحجوزات وطلبات التواصل بس.
- **Railway** مالوش طريقة مجانية مضمونة نعرف منها ميعاد الدفع. حط التاريخ بنفسك في `config/rules.yaml` تحت `subscriptions`، ورامي بيفكّرك قبلها بأسبوع.
- **OpenStreetMap** في بنها ممكن يكون ناقص. أول تشغيل هيقولك اتلقى كام محل.
